# 夜读 · 小说阅读模式（v1.2）

一个浏览器扩展：把小说网站的章节页**完全替换**成独立的阅读界面——
站点自带的主题、排版、广告、弹窗全部看不见，只留下干净的正文。

**13 套主题**：纯色底 9 套（暖阳纸 / 夜读墨 / 护眼青 / 极简白 / 樱花粉 / 咖啡奶 / 薰衣紫 / 深海蓝 / 曜石黑）
+ 多色渐变场景主题 4 套（**晚霞** 橙粉紫渐变、**星空** 深蓝紫多层光晕、**青瓷** 影青渐变、**蜜桃** 蜜桃奶油渐变）。

> **第一次安装**：双击本文件夹里的 `install-guide.html`，按四个步骤点完即可（约 1 分钟，全程鼠标，无命令行）。

## 怎么用（三步）

1. 打开任意小说的**具体一章**（目录页 / 书页不会触发，这是刻意的）
2. 页面**右下角**出现「阅读模式 · 只看正文」按钮，点它
3. 首次进入有一张引导卡：勾选「以后打开本站直接进入阅读模式」，之后连点都不用点

阅读中：

| 想做什么 | 怎么做 |
|---|---|
| 上一章 / 下一章 | 点顶部按钮，或按 `←` `→`（**不刷新整页**，秒切） |
| 往下读 | `空格` 或滚动 |
| 调字号 / 背景 / 字体 | 右上角「设置」，或用 `+` `-` `T` |
| 每行字数（页宽） | 设置里「每行字数（页宽）」滑块 |
| 退出回原网页 | 右上角「退出」，或 `Esc` |
| 随时开关 | `Alt + R`，或点工具栏图标 |

## 本轮针对「第一次用的新手」做的优化

按 `strict-product-inspector` 的用户画像 1（急躁的新手：不读说明、找不到入口就差评）逐条实测后修改：

| 原来的坑 | 现在 |
|---|---|
| 入口按钮写「净读」，生造词看不懂，只有 13px 竖条 | 改成右下角大按钮「**阅读模式 · 只看正文**」，带书本图标；首次出现还有气泡「点这里 → 去掉广告和排版」 |
| 进阅读界面后不知道能干什么 | 首次进入给一张引导卡，四行讲完：翻章、翻页、退出、调字号；并可直接勾选「以后自动进入」 |
| 顶部按钮栏滚动 2 秒后自动消失，新手找不到回去的路 | 默认**一直显示**，想要沉浸再手动改成「往下读时收起」 |
| 点「下一章」整页刷新：白屏、广告重载、还要重新点按钮 | 改为 **fetch 无刷新换章**：正文就地替换、URL 同步、失败才退回整页跳转 |
| 设置里写「版心宽度」「行距」，不知道是什么 | 改成「每行字数（页宽）」「行间距」，字号还给 `A－` / `A＋` 大按钮 |
| 点入口没反应，不知道是坏了还是没识别 | 按钮原地变红显示「这页没找到正文」 |
| 扩展面板里"未识别到章节正文"这类技术话 | 改成「这一页可以净化阅读 / 这一页没找到正文」，并给「再检测一次」 |
| 关掉标签页就找不到上次读到哪 | 面板顶部「上次读到」，一键跳回那一章 |
| 安装要照着 4 行文字在设置页里摸 | 新增 `install-guide.html`：大字步骤 + 一键复制「扩展管理页地址」和「扩展文件夹路径」 |

## 设计依据（不是拍脑袋）

选择器与清洗规则来自对真实站点的抓取分析（快照见项目 `../research/` 目录）：

| 模板家族 | 实测站点 | 真实结构 |
|---|---|---|
| 杰奇CMS（最大的一族） | 3zmxsw.cc | `<div id="content" class="showtxt">`，`<br />` 分隔，正文里混 `<script>` 与"首发域名"广告 |
| 笔趣阁365 型 | biquge365.net | `#neirong > #txt`，`<br>` + `&nbsp;` 缩进，`body#moshi` 主题类，正文内嵌广告行 |
| 新版 bqg 型 | xbiqugew.com | `body.novel_info` + `.detail-box / .first_txt` |
| SPA 型 | bqg128.com | 首屏只有 `#loading`，正文由 JS 注入 → 扩展会等待 |
| JS 反爬型 | beqege / uuks5 | 首屏是 5KB 挑战页 → 同样等待正文出现 |

对于没见过的新站，扩展用**通用正文打分算法**兜底：字数 + 标点密度 + 段落数打分，
按链接密度、容器签名、广告位数修正——这正是它敢说"适配大部分站"的底气。

## 它对真实站点做了哪些清理

- 正文里的 `<script>` 注入、`iframe` 广告位：整块剔除
- 「一秒记住【笔趣阁】…」「请记住本书首发域名…」等广告句：**埋在段落中间也只剜除该句**，不丢正文
- 「（本章未完，请点击下一页）」+ 同站分页：自动抓取后续页并合并（最多 3 页）
- `&nbsp;` / 全角空格缩进：归一化为段落，首行统一缩进
- 重复出现的分页标题行：去重

## 已知边界

- 目录页 / 详情页不会触发（只在章节页生效），这是刻意设计
- 正文藏在 `iframe` 里的站（极少）暂不支持
- 站点用 JS 点击翻页（无真实链接）时无法自动合并分页；无刷新换章也会退化为整页跳转
- 扩展在所有 http/https 页面注入检测脚本，但只在判定为章节页时才显示入口；
  介意全站注入的话，可把 `manifest.json` 里 `content_scripts.matches` 改成你常去的站点域名
